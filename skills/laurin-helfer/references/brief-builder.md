# Brief-Builder

Für den Start einer neuen Website, Landingpage oder eines Shops. Ein guter Brief spart zehn Korrekturschleifen.

## So gehst du vor

1. Frag nicht alles einzeln ab. Gib ihr die Vorlage unten und lass sie ausfüllen, was sie schon weiß.
2. Lücken danach mit höchstens zwei, drei Fragen schließen.
3. Dann noch kein Code. Erst zwei Design-Richtungen in Worten vorschlagen, sie wählt.
4. Neues Website-Projekt heißt: neuer Chat. In der Desktop-App am besten ein eigenes Projekt pro Kunde oder Shop.

## Vorlage (zum Ausfüllen)

```
Projektart: [Website / Landingpage / Shopify-Shop]
Name / Marke: [...]

Ziel (ein Satz): Besucher sollen [anrufen / kaufen / buchen / sich eintragen].
Zielgruppe: [wer, wie alt, was ist denen wichtig]

Vibe: [3 Adjektive], aber nicht [1 Adjektiv, das es auf keinen Fall sein soll]
Referenzen:
- [Link 1]: mir gefällt [Schrift / Farben / Bilder / Aufbau]
- [Link 2]: mir gefällt [...]
- [Link 3]: mir gefällt [...]

Seiten: [Start, Über uns, Leistungen, Kontakt, Impressum, Datenschutz ...]
Must-haves: [Buchungs-Tool, Newsletter, Instagram, Produktfilter ...]
No-Gos: [z. B. dunkles Design, Stockfotos, lila Verläufe]

Vorhanden: [Logo / Farben / Fotos / Texte / nichts davon]
Technik: [Shopify / statische Seite / weiß ich nicht]
Rechtliches: [Impressum, Datenschutz, beim Shop AGB, Widerruf, Versand]
Deadline: [...]
```

## Prompt nach dem Brief

```
Hier ist mein Brief: [Brief einfügen]

Bitte:
1. Stell mir höchstens drei Fragen zu echten Lücken.
2. Schlag mir dann zwei unterschiedliche Design-Richtungen vor, in Worten:
   Farben (mit Hex), Schriften, Bildstil, Stimmung, ein Beispielsatz für die Startseite.
3. Noch kein Code. Ich wähle eine Richtung, dann schreiben wir die DESIGN.md.
```

## Was Laurin aus vielen Projekten gelernt hat

Bring das ein, wenn es passt. Nicht als Vortrag.

- Bei Shops aus der Welt der Kundschaft starten: Licht, Fotos, Lifestyle. Nicht automatisch dunkel.
- Startseite als ruhiger Verteiler, etwa sechs Blöcke. Details auf Unterseiten.
- Der eigene Look der Marke schlägt generische Skill-Regeln.
- Designentscheidungen nur an echten Bildern treffen, nicht an Beschreibungen.
- Eine Richtung als echtes, fertiges Hero zeigen, nicht als schnelle Skizze oder kleine Kacheln.
- Text-only und statisch fällt durch: echte Fotos, etwas Bewegung.
- Keine Fake-Bewertungen, keine erfundenen Zahlen.

## Standard-No-Gos (typischer KI-Look)

Wenn sie keine eigenen No-Gos hat, schlag diese vor:

- Lila-blaue Verläufe
- Hero plus drei gleiche Karten
- Überall dieselben runden Ecken und Schatten
- Icons in runden Quadraten
- Emoji-Aufzählungen
- Unverändertes Standard-Grau aus UI-Bibliotheken
- Glas-Effekt aus Reflex
- Kleine Überschriften in Großbuchstaben über jeder Section
- Pfeil auf jedem Button
- Jede Section blendet von unten ein
- Hüpfende Animationen
- Reines Schwarz

## Brief für einen Shop: Extra-Fragen

- Wie viele Produkte, wie viele Varianten (Größen, Farben)?
- Woher kommen die Produktfotos?
- Versand: wohin, wie teuer, ab wann gratis?
- Bezahlarten: reicht Shopify Payments plus Klarna?
- Gibt es schon einen Shopify-Account oder einen Dev-Store?

Für alles Weitere zum Shop: `shopify-workflow.md`.
