01 · Werkzeug-Garage

Denken in der App, bauen in Antigravity.

Zwei Werkzeuge, zwei Jobs. Wer im Chat Code baut oder in der IDE Texte grübelt, macht sich das Leben schwer.

Claude-Desktop-App

Zum Denken

  • Briefs, Texte, Pläne: im Chat oder in einem Projekt mit Anweisungen und Wissensdateien.
  • Recherche mit /deep-research oder „+“ › Research. Bezahlte Pläne, frisst Limit.
  • Design-Entwürfe mit Claude Design, direkt im Chat oder im Artifacts-Tab. Export als HTML oder ZIP.
  • Skills unter Customize › Skills, Connectors wie Shopify unter Customize › Connectors.
  • Code-Tab: Claude Code ohne Terminal, mit Browser-Vorschau deiner Seite.
  • Hier wohnt auch Pixel-Laurin als Zeige-Buddy.

Antigravity mit Claude

Zum Bauen

  • Code, Dateien, ganze Projektordner.
  • Claude Opus 5.5 und Sonnet 5.5 (Thinking) im Dropdown unter dem Eingabefeld. Braucht Google AI Pro, Ultra oder Enterprise.
  • Regeln in .agents/rules/, mit trigger-Zeile oben, sonst werden sie ignoriert.
  • Skills mit npx skills add <repo> -a antigravity -g -y, auf Windows plus --copy.
  • Plan B: die offizielle Erweiterung „Claude Code“ aus dem Extensions-Panel, läuft über dein Claude-Abo.
  • Keine Workflows mehr bauen: Die hören am 19.10.2026 auf.

Welches Modell wann?

  • Sonnet 5.5Alltag, Bauen, Routine. Schont das Limit.
  • Opus 5.5Knifflige Bugs, große Pläne, Research.
  • Haiku 5.5Kleinkram: Texte umformulieren, kurze Fragen.
  • Fable 5.1Auf Max dabei, auf Pro nur über Usage-Credits. Frisst viel.

Effort (Low bis Max) findest du im Menü neben dem Senden-Knopf: Low für Kleinkram, High für harte Nüsse.

        06 · Shopify-Mall
        
Shops? Shopify.

        
Laurin sagt: Selbstgebaute Shops über Claude sind Quatsch. Claude kann dir einen Warenkorb bauen. Aber Checkout, Zahlungen, Steuern und Sicherheit sind kein Wochenendprojekt.

      

      

        

          Selbstgebaut mit Claude
          vs
          Shopify
        

        
    
          
  • Selbstgebaut: Claude baut dir einen Checkout. Ob der sicher ist, merkst du beim ersten Kunden.
    Shopify: Den Checkout pflegt Shopify, sicher nach PCI-DSS Level 1.
    • 
          
  • Selbstgebaut: Server, Zertifikat, Backups: alles deine Baustelle.
    Shopify: Hosting und SSL sind inklusive.
    • 
          
  • Selbstgebaut: Zahlungsanbieter anbinden heißt: ein Wochenende API-Doku.
    Shopify: Shopify Payments: 2,1 % + 0,30 € pro Zahlung (Basic), Klarna 2,99 % + 0,35 €.
    • 
          
  • Selbstgebaut: Steuersätze pflegst du von Hand und hoffst.
    Shopify: Die MwSt. rechnet Shopify automatisch. Abführen bleibt deine Sache.
    • 
          
  • Selbstgebaut: Widerruf, AGB, Versand: abtippen und Daumen drücken.
    Shopify: Die Seiten werden generiert. Deutsche Texte am besten aus einer Kanzlei-App, das Impressum machst du selbst.
    • 
          
  • Selbstgebaut: Claude rät, wie dein eigener Code gemeint war.
    Shopify: Shopify AI Toolkit und Dev MCP geben Claude die echte Shopify-Doku.
    • 
          
  • Selbstgebaut: Kostet „nichts“. Außer deine Abende.
    Shopify: Basic: 36 € im Monat, 27 € bei jährlicher Zahlung. Testen: 3 Tage, dann 1 € im Monat für 3 Monate.
    • 
        

        
Preise Deutschland, Stand Oktober 2026. Fremde Zahlungsanbieter kosten auf Basic 2 % extra. OSS wird ab 10.000 € EU-Fernverkauf Thema.

      


      

        

          
Sicher mit Claude am Theme arbeiten

          
    
            
  1. Dev-Store nutzen. Nie am echten Shop üben.
    2. 
            
  2. Theme holen: shopify theme pull
    3. 
            
  3. Lokal entwickeln: shopify theme dev --store <shop> startet ein verstecktes Entwicklungs-Theme mit Live-Reload.
    4. 
            
  4. Prüfen und Vorschau: Theme Check, dann shopify theme push --unpublished.
    5. 
            
  5. Live schaltest du selbst im Admin. Nie --live, --publish oder --allow-live.
    6. 
          

        

        

          
Zum Kopieren

          

            
Wir arbeiten an meinem Shopify-Theme. Regeln für diese Sitzung:
- Nur Dev-Store oder unveröffentlichtes Theme.
- Erlaubt: shopify theme pull, shopify theme dev, shopify theme check,
  shopify theme push --unpublished.
- Verboten: --live, --publish, --allow-live. Live schalte ich selbst im Admin.
- Bevor du einen Befehl ausführst: zeig ihn mir und sag in einem Satz, was er tut.
Erste Aufgabe: [...]

            
          

          

            
Bau mir eine neue Section für mein Theme: [was sie zeigen soll].
Halte dich an die Theme-Standards (Liquid, Barrierefreiheit) und prüf
den Liquid-Code mit dem Shopify AI Toolkit.
Texte, Bild und Farben sollen im Theme-Editor einstellbar sein.
Zeig mir erst den Plan: welche Dateien, welche Einstellungen. Dann warte.

        08 · Superkräfte-Labor
        
    Was Claude seit Kurzem kann, und wo du es findest.
    
        
    Stand Oktober 2026, Desktop-App auf Windows. Menünamen in Anführungszeichen sind englisch, so wie in der App.
    
      
    
      
      
        
    • Projekte
      „+ New Project“ › „Set project instructions“
      Ein Projekt pro Website: Claude kennt Marke, Farben und Regeln, ohne dass du sie wiederholst. Jedes Projekt hat sein eigenes Memory.
      • 
        
    • Memory
      Settings › Memory › Topics
      Sieh nach, was Claude sich über dich gemerkt hat, und korrigier es.
      • 
        
    • Eigene Skills
      Customize › Skills › „+“ › „Upload a skill“
      Laurin-Helfer und Design-Skills direkt in der App, auf allen Plänen.
      • 
        
    • Claude Design
      In jedem Chat und im Artifacts-Tab
      Design-Entwürfe ausprobieren, als HTML oder ZIP exportieren und an Claude Code übergeben.
      • 
        
    • Research
      „+“ › Research oder /deep-research
      Konkurrenz und Markt gründlich recherchieren lassen. Bezahlte Pläne, frisst Limit.
      • 
        
    • Shopify-Connector
      Customize › Connectors
      Produkte, Lager und Rabatte per Chat. Nur mit dem Dev-Store testen.
      • 
        
    • Code-Tab
      Desktop-App, bezahlter Plan
      Claude Code ohne Terminal, mit Browser-Vorschau der laufenden Seite und Plan-Modus.
      • 
        
    • Modell und Effort
      Menü neben dem Senden-Knopf
      Sonnet und Low für Routine, Opus und High für harte Nüsse. Spart Limit.
      • 
        
    • Erweiterungen
      Settings › Extensions
      Hier läuft Pixel-Laurin. Eigene .mcpb-Dateien per Doppelklick installieren.
      • 
        
    • Verbrauch
      Settings › Usage
      Zeigt, wann dein Limit zurückgesetzt wird.

      4.
